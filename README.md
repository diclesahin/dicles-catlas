
# Dicle's Catlas 🐾🌍

## About the Project

Dicle's Catlas is my personal Web GIS portfolio,
developed for the GMT 458 Web GIS course at
Hacettepe University.

The website combines my academic background in
Geomatics Engineering with my interest in
traveling, geography, and digital mapping.

## Website Pages

- Home (index.html): Personal introduction,
  education, technical skills, and internships.
- Technologies (technologies.html):
  A table introducing web technologies with images.
- My Maps (maps.html):
  Interactive maps using OpenLayers and Leaflet.

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenLayers
- Leaflet
- Leaflet.markercluster
- Git and GitHub

## Interactive Maps

### OpenLayers Map

Displays an interactive geographic map using
an Esri topographic basemap.

### Leaflet Travel Map

Displays 13 cities that I have visited in
Türkiye and Europe.

Custom paw markers represent the cities.

The project implements zoom-dependent marker
visibility and settings to prevent horizontal
world repetition.

Marker clustering is included if successfully
enabled and tested.
